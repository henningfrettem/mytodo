A quiet place for lists

Todo.

Pick a folder on your laptop. The app will keep a todos.json file inside, along with any images you paste. Move the folder, and everything moves with it.

Your tasks never leave your machine. There's no account, no sync, no tracking. If you lose the folder, you lose the todos — back it up by copying the folder somewhere, or put it inside OneDrive/Dropbox if you want that sort of thing.

This browser can't do direct file access. Use Microsoft Edge or Google Chrome on Windows/Mac. The File System Access API isn't in Firefox or Safari yet.
